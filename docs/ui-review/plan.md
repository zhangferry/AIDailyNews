# 日报阅读体验改版

目标：保持 Astro / Svelte 和现有采集数据，改善首页、日报正文、归档的阅读效率。

## 源码确认的问题
- 元信息、图片和粗体摘要连成同一个 Markdown 段落。
- 正文不限制阅读宽度；标题、来源、摘要缺乏稳定层级。
- 归档页面重复标题；flex 子项宽度加 gap 易产生不稳定换行。
- 全量标签先于标题显示，移动端导航和工具在同一行争夺空间。
- 首页显示当前日期，但内容可能属于另一期。

## 实施顺序
1. 先以 AST fixtures 锁定正文兼容转换：不丢失链接、图片、摘要、列表及旧文章内容。
2. 添加轻量 rehype 转换，将旧文元信息与图片分离、分类和文章分组、导读链接化。
3. 用共享日报阅读组件统一首页与正文：刊期标题、文章数量、阅读时间、正文、桌面目录、移动端目录。
4. 收敛到纸白底、深墨文字、克制绿强调色；统一间距、可见焦点与中文导航。
5. 修复归档重复标题和栅格；验证生产构建、类型、lint 和页面结构。
6. 浏览器可用后检查桌面、移动端、深色、目录、搜索、归档和历史日报。

## 审阅约束
内容转换与视图分离；不改新闻内容、不迁移框架、不添加运行依赖。最终独立审阅内容保留和导航可用性。
